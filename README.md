# 我們認識的蔣萬安

獨立的純靜態公開貼文牆，延續 `shen-post-wall` 已驗證的資料模式與互動方式，但不共用資料，也不修改原專案。

## 原則

- 只收錄公開、第一人稱、可回到原文核對的內容。
- 不替任何人撰寫、補完或推測證詞。
- 不下載或轉載 Facebook／Threads 全文與照片；使用官方嵌入及原文連結。
- 若原文下架、改為非公開或關係無法核對，移除該筆資料。
- 本站必須保留「非官方網站」標示。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `index.html` | 頁面結構、說明與安全政策 |
| `styles.css` | 獨立的藍色視覺系統與響應式版面 |
| `posts.js` | 已核對的公開原文清單，目前刻意留空 |
| `app.js` | 卡片、搜尋、篩選、排序與分享 |

## 本機預覽

在此資料夾執行：

```sh
python3 -m http.server 8010
```

再開啟 <http://localhost:8010>。
